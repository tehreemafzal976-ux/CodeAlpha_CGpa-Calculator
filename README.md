# 🎓 GPA & CGPA Calculator (C++)

A structured and object-oriented GPA & CGPA Calculator developed in C++ as part of my internship tasks at CodeAlpha.
## 📌 Project Overview
This project calculates a student's Semester GPA and overall CGPA based on:

- Course names
- Letter grades
- Credit hours
It applies standard grade point mapping and computes weighted averages to produce accurate academic results.
## 🚀 Features

- Accepts input for multiple courses
- Supports grade-based GPA calculation (A+, A, A-, B+, etc.)
- Calculates:
  - Grade points per course
  - Earned grade points (grade × credit hours)
  - Total credit hours
  - Total grade points
  - Semester GPA
- Displays a formatted report card
- Uses Object-Oriented Programming (OOP) concepts
## 🧠 Concepts Used

- Classes and Objects  
- Structures  
- Dynamic Memory Allocation  
- Functions and Modularity  
- Conditional Logic  
## 🛠️ Technologies Used
- C++
- Standard Library (iostream, string)
## ▶️ How to Run

1. Open the project in any C++ compiler (Dev C++, VS Code, etc.)
2. Compile the program
3. Run the executable
4. Enter:
   - Number of courses
   - Course name
   - Grade (e.g. A, B+, C)
   - Credit hours
5. View the generated report card with GPA
